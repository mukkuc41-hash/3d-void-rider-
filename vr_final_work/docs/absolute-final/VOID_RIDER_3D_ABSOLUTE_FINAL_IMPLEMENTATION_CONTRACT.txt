H. EMERGENCY ESCAPE SEQUENCE 1 — INSIDE THE SAME DOME
The sequence occurs within the same spherical orbital station. A lower/basement-style parking level may be part of the same dome, connected by ramps/lifts, but must not become an unrelated separate garage.

Phase 1 — Intake:
- Surviving actual convoy ships enter and are assigned unique parking bays.
- Preserve SAVIOUR roster/roles when present.
- Stagger arrivals and prevent overlaps.
- Active selected ship stays player-controlled; all others stay AI-controlled.

Phase 2 — Alignment:
- Each ship uses a continuous approach to its assigned bay.
- Validate actual world-transform distance, speed, heading/orientation, height/landing alignment if relevant, and collision state.
- Misaligned/fast ships keep locks open and receive a correction prompt; retries must work.
- AI ships follow the same validation and retry safely.

Phase 3 — Physical locks:
- Every bay has visible clamp arms/brackets that physically animate around appropriate docking points.
- Clamps engage only after valid alignment and low speed.
- Use existing physics constraints if available; otherwise use a stable docked state that prevents jitter.
- Locks prevent steering, boost, AI movement, and unintended drift.
- HUD text “PARKING LOCKS ENGAGED — RELEASE REQUIRED” reflects the actual lock state.
- Movement must never resume while the physical locks are still engaged.

Phase 4 — Lockdown:
- Once required ships are secured, animate relevant blast doors/shutters, warning lights, alarms, and emergency lighting.
- Show “CONVOY SECURED”, “LOCKDOWN ACTIVE”, and a clear next objective.
- Keep interaction available; avoid an excessively long unskippable cinematic.
- Ensure deterministic transitions and safe restart behavior.

Phase 5 — Release:
- Player activates the emergency release through the shared input/action system.
- Visible clamps retract before movement returns. Any hold-field visual powers down after lock disengagement.
- Bay indicators change to released/ready.
- If safety prerequisites are unmet, block release and explain why.
- Same action works across supported keyboard, touch, and gamepad controls.

Phase 6 — Emergency exit:
- Open a visible emergency door/airlock connected to the same dome's deck.
- Create a continuous escape route from bays to the exit checkpoint.
- Lead guard takes point where supported; cargo remains protected; rear guards cover the rear where supported.
- Selected ship remains player-controlled and others remain AI-controlled.
- Preserve collision avoidance, physics, route following, checkpoints, and damage.
- No teleporting, skipped route, or physics bypass.
- Add safe retry/recovery for stalled or misaligned ships.

Phase 7 — Completion:
- Complete only after the required surviving ships pass the actual emergency-exit checkpoint and all mission conditions are satisfied.
- Preserve cargo survival, convoy survival, damage, time, checkpoints, and results.
- Use existing mission state machine/results UI.
- SAVIOUR completion follows escort/cargo objectives.
- HUNTERS remains its own combat mission. Do not force it into this escape sequence unless the existing mission flow explicitly requires it.
